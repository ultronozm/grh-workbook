Prerequisites.

Fermat’s little theorem, Euler’s criterion, Legendre’s formula for \(\operatorname{ord}_p n!\), Stirling’s formula, the Euler–Maclaurin formula, Mertens’ estimate \(\sum_{p \le x} \log p/p = \log x + O(1)\), and Chebyshev’s bound \(\theta(N) := \sum_{p \le N} \log p \le N \log 4\). Quadratic fields and the Kronecker symbol \(\chi_D\); every primitive real character is a \(\chi_D\) [Dav, Ch. 5]. Section 7.2 uses Section 5.2 of Chapter 5. We follow [N, App. D]. Section 7.4 uses the function \(G\) of (1) in Chapter 1. Sections 7.4–7.5 point ahead to Sections 8.1–8.5 of the next chapter, Chapter 8, but use nothing from it.

§7.1. Chebyshev’s determinant Tag 229B

How much can the size and divisibility of one integer say about primes? For \(N \ge 2\) let \(V_N := \det(u^a)_{1 \le u \le N,\, 0 \le a < N} = \prod_{1 \le i < j \le N} (j - i)\).

Tag 229C

Problem 7.1.1. \(V_N = \prod_{a < N} a!\), and \(\log V_N \le \frac12 N(N-1) \log N\).

Tag 229D

Problem 7.1.2. \(\operatorname{ord}_p V_N \ge \sum_{a < N} \lfloor a/p \rfloor \ge N^2/(2p) - N/2\). For \(N = 4\), \(p = 2\) the first inequality is an equality.

Tag 229E

Problem 7.1.3. \(\sum_{p \le N} \log p/p \le \log N + 2\).

Used in: Problem 7.3.4

Each prime is seen through the single congruence \(u^p \equiv u \pmod p\), once for each complete block of \(p\) exponents. This proof is given in [N, App. A], which credits the observation to Pascadi and to Tao [Tao].

§7.2. The Frobenius graph Tag 229F

Let \(D\) be a fundamental discriminant, \(F := \mathbb{Q}(\sqrt D) \subset \mathbb{C}\), \(\sigma\) the nontrivial automorphism, and \(\mathcal{O}_F= \mathbb{Z}[\omega]\) with \(\omega = (1 + \sqrt D)/2\) or \(\sqrt D/2\). We want \(\sum_{p \le t,\, \chi_D(p) = -1} \log p/p \le (\frac12 + o(1)) \log t\).

Tag 229G

Problem 7.2.1. If \(p\) is odd and \(\chi_D(p) = -1\), then \(u^p \equiv \sigma(u) \pmod{p\mathcal{O}_F}\) for all \(u \in \mathcal{O}_F\). For instance, \((1 + i)^3 \equiv 1 - i \pmod 3\).

So modulo such \(p\) the points \((u, \sigma(u))\) lie on the graph \(Y = X^p\). This is all that Section 5.2 of Chapter 5 used about \(\mathbb{Z}[i]\), and we now run that section with \(\mathbb{Z}[i]\), \(\bar u\) and the primes \(p \equiv 3 \pmod 4\) replaced by \(\mathcal{O}_F\), \(\sigma(u)\) and the odd primes \(p\) with \(\chi_D(p) = -1\). For integers \(t \ge 2\), \(H \ge 1\) let \(\mathcal{T}:= \{(a, b) \in \mathbb{Z}_{\ge 0}^2 : a + Hb < t\}\), \(T := \lvert \mathcal{T}\rvert\), \(A := \sum_\mathcal{T}a\).

Tag 229H

Problem 7.2.2. Problem 5.2.2 holds in this setting: if \(p\) is odd, \(\chi_D(p) = -1\), \(f \in \mathcal{O}_F[X, Y]\) and \(u \in \mathcal{O}_F\), then \(\bigl(\partial_X^j ((X^p - Y)^k f)\bigr)(u, \sigma(u)) \in p^k \mathcal{O}_F\) for all \(j, k \ge 0\).

Let \(u_1, \dots, u_I \in \mathcal{O}_F\), \(J \ge 1\), and let \(M\) be the \(IJ \times T\) matrix with entries \((\partial_X^j X^a Y^b)(u_i, \sigma(u_i))\), \(0 \le j < J\). Let \(P_H\) be the set of odd \(p \ge H\) with \(\chi_D(p) = -1\), and \(k_p := \sum_\mathcal{T}\lfloor a/p \rfloor\).

Tag 229J

Problem 7.2.3. For \(p \in P_H\), the set \(\mathcal{T}\) satisfies the hypothesis of Problem 5.2.3, and every \(T \times T\) minor of \(M\) lies in \(p^{k_p} \mathcal{O}_F\).

Tag 229K

Problem 7.2.4. Let \(\lvert u_i \rvert, \lvert \sigma(u_i) \rvert \le B\) with \(B \ge 1\), and let \(\delta\) be a nonzero \(T \times T\) minor. Then \(\delta\sigma(\delta)\) is a nonzero integer divisible by \(p^{2k_p}\) for \(p \in P_H\), and \(\lvert \delta \rvert, \lvert \sigma(\delta) \rvert \le T^T t^{T(J-1)} B^{\sum_\mathcal{T}(a + b)}\).

Problems 7.2.1–7.2.4 prove the following, which for \(\mathbb{Z}[i]\) also follows from Theorem 5.2.1.

Tag 229L

Theorem 7.2.1. If \(\lvert u_i \rvert, \lvert \sigma(u_i) \rvert \le B\), \(B \ge 1\), and \(M\) has rank \(T\), then \[\begin{equation} \label{eq:star}\tag{1} \sum_{p \in P_H} k_p \log p \le \Bigl( \sum_\mathcal{T}(a + b) \Bigr) \log B + T\log T + T(J - 1)\log t . \end{equation}\]

Used in: Problem 7.3.2
Tag 229M

Problem 7.2.5. If \(I \ge \lvert D \rvert\), there are \(I\) distinct \(u \in \mathcal{O}_F\) with \(\lvert u \rvert, \lvert \sigma(u) \rvert \le 4 I^{1/2} \lvert D \rvert^{1/4}\).

Used in: Problem 7.3.3

§7.3. Density one half Tag 229N

Without derivatives, (1) gives nothing in a quadratic field [N, Ex. 24].

Tag 229P

Problem 7.3.1. Distinct \(u_i \in \mathcal{O}_F\) with \(\lvert u_i \rvert, \lvert \sigma(u_i) \rvert \le B\) number at most \(25B^2\). Hence if \(J = 1\) and \(M\) has rank \(T\), then \(\log B \ge \log t - \frac12\log H - 3\).

So for \(J = 1\) the bound from (1) for \(\sum_{H \le p \le t,\, \chi_D(p) = -1} \log p/p\) is at least \(\log t - \frac12 \log H - 3\), worse than Mertens’ \(\log(t/H) + O(1)\). Derivatives let \(I\) be about \(T/J\) [Gr]. The interpolation input, by a Wronskian argument that [Ko, proof of Thm. 1] and [N, Lemma 17] credit to Barreto: if the \(u_i\) are distinct, \(I = 2t\) and \(J = 2\lfloor (t-1)/H \rfloor + 1\), then \(M\) has rank \(T\). For \(t \ge 6\), \(1 \le H \le t/2\) one has \(T \le t^2/H\), \(A \ge t^3/(8H)\) and \(\sum_\mathcal{T}b \le 8A/H\).

Tag 229Q

Problem 7.3.2. Under the hypotheses of Theorem 7.2.1, with \(t \ge 6\) and \(H \le t/2\), \(\sum_{p \in P_H,\, p \le t} \log p/p \le (1 + 8/H)\log B + (8/t)\bigl(\log T + (J-1)\log t\bigr) + 16\).

Tag 229R

Problem 7.3.3. For \(t \ge \max(16, \lvert D \rvert/2)\), \(H = \lceil \log t \rceil\), \(I = 2t\), \(J = 2\lfloor (t-1)/H \rfloor + 1\) and the points of Problem 7.2.5, \[\sum_{p \le t,\ \chi_D(p) = -1} \frac{\log p}{p} \le \frac12 \log t + \frac14 \log\lvert D \rvert + \log\log(3t) + 50 .\]

Used in: Problem 7.3.4

A primitive real \(\chi\) of conductor \(q\) has no real zero in \((1 - c/\log 2q, 1)\), with \(c\) effective and depending only on \(\kappa, B_0\), provided \(\sum_{p \le x,\, \chi(p) = -1} \log p/p \le \kappa\log x + B_0\log 2q\) for all \(x \ge 2\) and some \(\kappa < 1\) [N, Lemma 2, App. F].

Tag 229S

Problem 7.3.4. Problems 7.1.3 and 7.3.3 give the bound on the sum with \(\kappa = \frac34\), \(B_0 = 30\).

Thus we have proved the following.

Tag 229T

Theorem 7.3.1. There is an effective absolute \(c > 0\) such that \(L(s, \chi) \ne 0\) for real \(s > 1 - c/\log(2q)\), for every primitive real character \(\chi\) of conductor \(q\).

This was first proved in [OAI], with three variables in a biquadratic field; the proof here follows [Gr] and [N].

§7.4. One congruence per block Tag 229U

Alpöge called this argument “Stepanov without multiplicity” [Alp]. What does it lose? For \(V_N\) both sides are exact. Let \(r_n\) be the remainder of \(N\) modulo \(n\), and \(W(N) := \sum_{n \le N} \Lambda(n)\, r_n(n - r_n)/(2n)\).

Tag 229V

Problem 7.4.1. \(\sum_{a < N} \lfloor a/n \rfloor = \frac N2 \bigl(\frac Nn - 1\bigr) + \frac{r_n(n - r_n)}{2n}\). Hence \(\log V_N = \frac N2 \sum_{n \le N} \Lambda(n)\bigl(\frac Nn - 1\bigr) + W(N)\), with \(0 \le W(N) \le N\psi(N)/8\), where \(\psi(N) := \sum_{n \le N} \Lambda(n)\).

Tag 229W

Problem 7.4.2. For \(G\) as in (1) of Chapter 1, \(G(N) = (\gamma - \frac12)N - 2W(N)/N + O(1)\). In particular \(G(N) \le (\gamma - \frac12)N + O(1)\).

For \(N = 10^4\), \(G(N) = 1.749\ldots\) while \((\gamma - \frac12)N = 772.15\ldots\). The determinant gives a one-sided bound for \(G\) with error of order \(N\), and nothing more: the rest is the sawtooth sum \(W(N)\). In Section 7.2 the floors \(\lfloor a/p \rfloor\) cost the constant \(16\) of Problem 7.3.2 in the same way. An error \(O(1)\) in \(\sum \log p/p\) is Chebyshev strength. It suffices for Theorem 7.3.1, where a real zero would change the main term by a constant factor. It is far from \(G(x) \le x^{1/2 + \varepsilon}\), which the Riemann hypothesis needs. One determinant is a chain of length \(m = 1\) in Problem 8.5.1.

§7.5. Multiplicity in Bombieri’s form Tag 229X

Stepanov’s polynomial vanishes to order about \(\sqrt q\) (Theorem 8.3.1); order one gives nothing (Problem 8.1.4). Bombieri gets multiplicity from a power of Frobenius [Bom74], [N, App. D].

Let \(k\) be a finite field of odd characteristic, \(f \in k[X]\) of degree \(d = 2g + 1\), \(g \ge 1\), and \(R := k[x, y]\) with \(y^2 = f(x)\). For \(\phi = a(x) + b(x)y\) let \(\lambda(\phi) := \deg(a^2 - b^2 f)\), and \(R_\ell := \{\phi : \lambda(\phi) \le \ell\}\).

Tag 229Y

Problem 7.5.1. \(\lambda(a + by) = \max(2\deg a, 2\deg b + d)\) and \(\lambda(\phi\psi) = \lambda(\phi) + \lambda(\psi)\); \(\dim_k R_\ell = \ell + 1 - g\) for \(\ell \ge 2g\).

Tag 229Z

Problem 7.5.2. A nonzero \(\phi \in R\) vanishes at no more than \(\lambda(\phi)\) points \((\xi, \eta)\) over a finite extension of \(k\).

Let \(Q\) be a power of \(\lvert k \rvert\), and \(N\) the number of \((\xi, \eta) \in \mathbb{F}_{Q^2}^2\) with \(\eta^2 = f(\xi)\). Let \(2g \le \ell_1 < Q\), \(\ell_2 \ge 2g\), and \((x_i)\), \((y_j)\) bases of \(R_{\ell_1}\), \(R_{\ell_2}\) with distinct \(\lambda\). For \(c_{ij} \in k\) let \(f_c := \sum c_{ij} x_i y_j^Q\) and \(\tilde f_c := \sum c_{ij} x_i^Q y_j\).

Tag 22A2

Problem 7.5.3. If \(c \ne 0\) and \(\tilde f_c = 0\), then \(f_c \ne 0\), \(f_c\) vanishes at all \(N\) points, and \(N \le \ell_1 + Q\ell_2\).

Tag 22A3

Problem 7.5.4. Such \(c\) exists for \(\ell_1 = Q - 1\), \(\ell_2 = Q + 2g\) if \(Q > (g+1)^2\). Hence \(N \le Q^2 + (2g+1)Q - 1\).

For \(f = X^3 - X\) over \(\mathbb{F}_3\) and \(Q = 27\), \(N = 783\) and the bound is \(809\). The function \(f_c^Q\) vanishes to order at least \(Q\) at each of these points, for free, because \((\sum c\phi)^Q = \sum c^Q\phi^Q\), \(c^Q = c\), and all points share the Frobenius \(\xi \mapsto \xi^{Q^2}\).

Tag 22A4

Problem 7.5.5. \((X + Y)^p - X^p - Y^p \in p\mathbb{Z}[X, Y] \setminus p^2\mathbb{Z}[X, Y]\). The primes \(p < 4000\) with \(2^p \equiv 2 \pmod{p^2}\) are \(1093\) and \(3511\).

Over \(\mathbb{Z}\) the \(p\)-th power is additive and fixes integers only modulo \(p\), and \(p\) varies. The determinant of Section 7.2 is nonzero by interpolation, handles all \(p \ge H\) because \(\mathcal{T}\) is stable under \(X^p \mapsto Y\), and sees \(p\) because \(X^p - Y\) vanishes at \((u, \sigma u)\) to first order modulo \(p\). In the proof the multiplicity returns through a chain of \(m\) maps (Theorem 8.4.1 of the next chapter), and the budget \(x/m + m\) of Problem 8.5.2 balances at \(m \approx \sqrt x\), as \(\ell\) and \(Q\) do above.
