Prerequisites.

The zeta function and Dirichlet \(L\)-functions as in [Dav]: the Hadamard product and the constant \(B\) (Ch. 12), the explicit formula for Chebyshev’s function \(\psi(x)\) and its contour shift (Ch. 17), and their analogues for \(L(s, \chi)\) (Ch. 12 and 19), with \(L(1, \chi) \ne 0\) (Ch. 4). Chebyshev’s bound \(\psi(x) \ll x\) [MV]. Mellin transforms. The theorems of Landau and of Kaczorowski–Pintz are stated in §1.2. Chapter 17 is used only for motivation, in §1.3.

A comparison of divisibility with size, as in Chebyshev’s method, gives upper bounds for weighted sums over primes, and nothing else. Can an upper bound for a sum over primes prove the Riemann hypothesis? This chapter shows that it can, for a suitable weight, following the reduction used in Alpöge’s argument [Alp]. The upper bound itself is not treated here.

§1.1. The ramp sum Tag 2223

Write \(v_+ := \max(v, 0)\) for real \(v\), and let \(\Lambda\) be the von Mangoldt function. The ramp at \(x\) is the function \(n \mapsto (x/n - 1)_+\): it is large for small \(n\), decreases, and vanishes for \(n \ge x\). Let \[\begin{equation} \label{eq:G}\tag{1} S(x) := \sum_{n} \Lambda(n) \Bigl(\frac{x}{n} - 1\Bigr)_+ , \qquad G(x) := S(x) - x \log x + (1 + \gamma) x , \end{equation}\] where \(\gamma\) is Euler’s constant, and let \(\psi(x) := \sum_{n \le x} \Lambda(n)\). The two subtracted terms are the main term of \(S\), as the problems show.

Tag 2224

Problem 1.1.1. For \(n \ge 1\) and \(\operatorname{Re}s > 1\), \(\int_1^\infty (x/n - 1)_+ \, x^{-s-1} \, d x = n^{-s}/\bigl(s(s-1)\bigr)\).

Tag 2225

Problem 1.1.2. \(S(x) = x \int_1^x \psi(t) \, t^{-2} \, d t\). Hence \(G(x) \ll x \log x\) for \(x \ge 2\).

Tag 2226

Problem 1.1.3. For \(\operatorname{Re}s > 1\), \[\begin{equation} \label{eq:F}\tag{2} F(s) := \int_1^\infty G(x)\, x^{-s-1} \, d x = -\frac{\zeta'}{\zeta}(s) \, \frac{1}{s(s-1)} - \frac{1}{(s-1)^2} + \frac{1 + \gamma}{s - 1} . \end{equation}\]

Tag 2227

Problem 1.1.4. \(F\) is meromorphic in \(\mathbb{C}\) and regular at \(s = 1\). Its poles in \(\operatorname{Re}s > 0\) are the zeros \(\rho\) of \(\zeta\) in the critical strip \(0 \le \operatorname{Re}s \le 1\), and a zero of multiplicity \(m\) gives residue \(-m/\bigl(\rho(\rho - 1)\bigr)\).

Tag 2228

Problem 1.1.5. The residue of \(F(s) x^s\) at \(s = 0\) is \(\log 2\pi\).

Problems 1.1.3–1.1.5 and a contour shift as in [Dav, Ch. 17], applied to \(-\frac{\zeta'}{\zeta}(s)\, x^s/(s(s-1))\), the part of \(F(s) x^s\) that comes from \(S\), where now every integral converges absolutely because of the factor \(1/(s(s-1))\), give the following.

Tag 2229

Theorem 1.1.1. For \(x > 1\), \[G(x) = \log 2\pi - \sum_\rho \frac{x^\rho}{\rho(\rho - 1)} + O(x^{-2}) ,\] where \(\rho\) runs over the zeros of \(\zeta\) in the critical strip with multiplicity, and the sum converges absolutely.

Tag 222A

Problem 1.1.6. \(\sum_\rho 1/\bigl(\rho(1 - \rho)\bigr) = 2 + \gamma - \log 4\pi = 0.0461\ldots\), with multiplicity.

Tag 222B

Problem 1.1.7. If the Riemann hypothesis holds, then \(\lvert G(x) - \log 2\pi \rvert \le (2 + \gamma - \log 4\pi)\sqrt{x} + O(x^{-2})\).

For instance \(G(10^4) = 1.749\), \(G(10^5) = 3.671\), \(G(10^6) = 11.040\) and \(G(2 \cdot 10^6) = -12.268\), to be compared with \(\log 2\pi = 1.838\) and \(0.0462 \sqrt{10^6} = 46.2\).

Tag 222C

Problem 1.1.8. Let \(\rho = \beta + i\gamma_0\) with \(\gamma_0 \ne 0\), and let \(c := -1/\bigl(\rho(\rho-1)\bigr)\). The joint term \(c x^\rho + \bar c x^{\bar\rho}\) of \(\rho\) and \(\bar\rho\) in Theorem 1.1.1 exceeds \(\lvert c \rvert x^\beta\) for all \(x\) in a set whose image under \(\log\) has density \(1/3\) in \([0, \infty)\), and it is less than \(-\lvert c \rvert x^\beta\) on another such set.

A zero with \(\beta > \frac12\) thus contributes to \(G\) terms of both signs, larger than \(\sqrt x\). A comparison of divisibility with size sees only one sign. The next section shows that one is enough.

§1.2. One side suffices Tag 222D

The following theorem is due to Landau [Lan]; see [MV, Lemma 15.1]. Let \(A \colon [1, \infty) \to \mathbb{R}\) be measurable and bounded on compact sets, with \(A(x) \ge 0\) for \(x \ge X_0\). Let \(\sigma_c\) be the infimum of the real \(\sigma\) with \(\int_1^\infty \lvert A(x) \rvert x^{-\sigma-1} \, d x < \infty\), and suppose that \(-\infty < \sigma_c < \infty\). Then \(H(s) := \int_1^\infty A(x) x^{-s-1} \, d x\) is holomorphic in \(\operatorname{Re}s > \sigma_c\), and it has no holomorphic continuation to a neighborhood of \(\sigma_c\).

Tag 222E

Problem 1.2.1. In this situation \(H(\sigma)\) is bounded below for real \(\sigma \in (\sigma_c, \sigma_c + 1]\).

Fix \(0 < \theta < 1\), suppose that \(G(x) \le x^\theta\) for all large \(x\), and let \(A(x) := x^\theta - G(x)\).

Tag 222F

Problem 1.2.2. \(-\infty < \sigma_c \le 1\), and \(H(s) = 1/(s - \theta) - F(s)\) for \(\operatorname{Re}s > 1\).

Tag 222G

Problem 1.2.3. \(\zeta(\sigma) < 0\) for \(0 < \sigma < 1\).

Tag 222H

Problem 1.2.4. If \(\sigma_c > \theta\), then \(\sigma_c\) is a real zero of \(\zeta\), and \(H(\sigma) \to -\infty\) as \(\sigma \downarrow \sigma_c\). Hence \(\sigma_c \le \theta\).

By Problem 1.2.3 the real zeros do not exist, but Problem 1.2.4 does not use this, and in §1.4 the same argument will be applied where real zeros cannot be excluded in advance. By Problem 1.2.4, \(F = 1/(s-\theta) - H\) is holomorphic in \(\operatorname{Re}s > \theta\), and by Problem 1.1.4 this excludes zeros there.

Tag 222J

Theorem 1.2.1. Let \(0 < \theta < 1\). If \(G(x) \le x^\theta\) for all large \(x\), then \(\zeta(s) \ne 0\) for \(\operatorname{Re}s > \theta\).

An upper bound obtained arithmetically will hold only for \(x\) in certain long intervals. The following theorem of Kaczorowski and Pintz [KP, Theorem 1 and Corollary 1], a quantitative form of Landau’s theorem, handles this.

Tag 222K

Theorem 1.2.2. Let \(f \colon (0, \infty) \to \mathbb{R}\) be locally integrable, and suppose that \(\Phi(s) := \int_0^\infty f(x) x^{-s-1} \, d x\) converges absolutely for \(\operatorname{Re}s\) large. Suppose that \(\Phi\) is regular in \(\operatorname{Re}s > \Theta\) but in no half-plane \(\operatorname{Re}s > \Theta - \eta\) with \(\eta > 0\), that \(\Phi\) is meromorphic in \(\operatorname{Re}s \ge \Theta - c_0\) for some \(c_0 > 0\), and that \(\Phi\) is regular at the real point \(\Theta\). Then for every \(\alpha > 0\) and every \(T \ge T_0(f, \alpha)\) there are points of \([T^{1-\alpha}, T]\) at which \(f\) is nonzero and of opposite signs.

The last hypothesis is needed: \(f(x) = x^\Theta\) for \(x \ge 1\) and \(f(x) = 0\) for \(x < 1\) satisfy the others, with \(\Phi(s) = 1/(s - \Theta)\).

Tag 222L

Problem 1.2.5. Let \(0 < \theta < 1\) and suppose that \(\zeta\) has a zero with real part greater than \(\theta\). Let \(\Theta\) be the supremum of the real parts of the zeros of \(\zeta\). Let \(f(x) := G(x) - 2x^\theta\) for \(x \ge 1\) and \(f(x) := 0\) for \(x < 1\). Then \(f\) and \(\Theta\) satisfy the hypotheses of Theorem 1.2.2.

If moreover \(G(x) \le x^\theta\) on \([Y, Y^{3/2}]\), then \(f(x) \le -x^\theta < 0\) there. Theorem 1.2.2 with \(\alpha = 1/4\) and \(T = Y^{3/2}\) finds a positive value of \(f\) in \([Y^{9/8}, Y^{3/2}]\) once \(Y\) is large. This proves the following; the exponent \(3/2\) may be replaced by any number greater than \(1\).

Tag 222M

Theorem 1.2.3. Let \(0 < \theta < 1\). If there are arbitrarily large \(Y\) such that \(G(x) \le x^\theta\) for all \(x \in [Y, Y^{3/2}]\), then \(\zeta(s) \ne 0\) for \(\operatorname{Re}s > \theta\).

Tag 222N

Problem 1.2.6. If for every \(\varepsilon > 0\) there are arbitrarily large \(Y\) with \(G(x) \le x^{1/2 + \varepsilon}\) for all \(x \in [Y, Y^{3/2}]\), then the Riemann hypothesis holds.

§1.3. Smoothing, and the triangle weight Tag 222P

Why the ramp, and not another weight? Let \(\phi \colon (0, \infty) \to \mathbb{R}\) be measurable, vanish on \((1, \infty)\), be bounded on compact subsets of \((0, 1]\), and satisfy \(\phi(t) = O(1/t)\) as \(t \to 0\). Let \[\psi_\phi(x) := \sum_n \Lambda(n) \phi(n/x) , \qquad \tilde\phi(s) := \int_0^\infty \phi(t) t^{s-1} \, d t \quad (\operatorname{Re}s > 1) .\] We write \(\tilde\phi(s)\) wherever the integral converges absolutely. The sharp cutoff \(\phi = \mathbf{1}_{(0,1]}\) gives \(\psi_\phi = \psi\) and \(\tilde\phi(s) = 1/s\). The ramp is \(\phi(t) = (1/t - 1)_+\), with \(\tilde\phi(s) = 1/(s(s-1))\) by Problem 1.1.1. The triangle weight is \(\phi(t) = (1 - t)_+\), with \(\psi_\phi(x) = x^{-1}\int_0^x \psi(t) \, d t\).

Tag 222Q

Problem 1.3.1. For \(\operatorname{Re}s > 1\), \(\int_0^\infty \psi_\phi(x) x^{-s-1} \, d x = -\frac{\zeta'}{\zeta}(s) \, \tilde\phi(s)\).

Tag 222R

Problem 1.3.2. For the triangle weight \(\tilde\phi(s) = 1/(s(s+1))\). If \(\phi_1(t) := \phi(t)/t\), then \(\tilde\phi_1(s) = \tilde\phi(s - 1)\); the ramp is the triangle weight divided by \(t\).

The following theorem is proved as Theorem 1.1.1: by Problem 1.3.1 with \(\tilde\phi(s) = 1/(s(s+1))\), shift the line of integration to \(\operatorname{Re}s = -3/2\) as in [Dav, Ch. 17], along horizontal segments at heights \(T\) where \(\zeta'/\zeta \ll \log^2 T\). The factor \(1/(s(s+1))\) makes every integral converge absolutely, and the poles of \(-\frac{\zeta'}{\zeta}(s)\, x^s/(s(s+1))\) to the right of \(-3/2\) are at \(1\), \(0\), \(-1\) and the zeros \(\rho\).

Tag 222S

Theorem 1.3.1. For \(x > 1\), \[\sum_{n \le x} \Lambda(n) \Bigl(1 - \frac{n}{x}\Bigr) = \frac{x}{2} - \log 2\pi - \sum_\rho \frac{x^\rho}{\rho(\rho + 1)} + O\Bigl(\frac1x\Bigr) .\]

As a check, the left side minus \(x/2 - \log 2\pi\) is \(0.106\), \(7.975\) and \(-12.115\) at \(x = 10^4\), \(10^6\) and \(2 \cdot 10^6\). For the ramp and the triangle weight \(\lvert \tilde\phi(\rho) \rvert \ll \lvert \rho \rvert^{-2}\), so the sums over zeros converge absolutely. For the sharp cutoff they do not, since \(\sum_\rho 1/\lvert \rho \rvert\) diverges.

Tag 222T

Problem 1.3.3. Let \(0 < \theta < 1\). If \(\sum_{n \le x} \Lambda(n)(1 - n/x) \le x/2 + x^\theta\) for all large \(x\), then \(\zeta(s) \ne 0\) for \(\operatorname{Re}s > \theta\).

The two smooth weights differ in one respect. A real zero \(\beta \in (0,1)\) contributes \(-x^\beta/(\beta(\beta - 1)) > 0\) to \(G(x)\), but \(-x^\beta/(\beta(\beta+1)) < 0\) to the sum of Theorem 1.3.1, so an upper bound for the latter does not see it. For \(\zeta\) this is harmless by Problem 1.2.3; for Dirichlet \(L\)-functions it is not (§1.4).

The ramp itself is forced by the arithmetic. Theorem 17.3.1 gives, at primes \(p \equiv 3 \pmod 8\), lower bounds for \(p\)-adic valuations of the form \(\sum_{i \text{ odd}} (\lfloor a/p^i \rfloor - w)_+\). Up to an error of \(1\) for each odd \(i\) with \(p^i \le a\), and with \(a = wx\), the summand is \((a/p^i - w)_+ = w(x/p^i - 1)_+\), which is \(w\) times the ramp at \(x\). Bounds of this form at every inert prime, summed with weights \(\log p\), give the ramp sum over odd powers of primes inert in an imaginary quadratic field; this is the subject of the sequel, Inert primes and Estimate B.

§1.4. Dirichlet \(L\)-functions Tag 222U

What replaces \(G\) for a Dirichlet \(L\)-function? For a primitive nonprincipal Dirichlet character \(\chi\) let \(c_\chi := \frac{L'}{L}(1, \chi)\) and \[\begin{equation} \label{eq:Gchi}\tag{3} G_\chi(x) := \sum_{n \le x} \Lambda(n) \chi(n) \Bigl(\frac{x}{n} - 1\Bigr) + c_\chi x . \end{equation}\] Let \(\psi\) be a primitive Dirichlet character of conductor \(M\) and order \(o\); from here on \(\psi\) is this character, not Chebyshev’s function. For \(1 \le j < o\) let \(\psi_j\) be the primitive character inducing \(\psi^j\). Let \[G^\psi(y) := G(y) + \frac{1}{3o + 1} \sum_{j=1}^{o-1} \operatorname{Re}G_{\psi_j}(y) .\] The weight \(1/(3o+1)\) is the one that arises from averaging over a subgroup in Fourier analysis on the Galois group (Problem 4.5.4); the positivity of the coefficients in Problems 1.4.1 and 1.4.2 only uses that it lies between \(0\) and \(1\).

Tag 222V

Problem 1.4.1. For \(n\) prime to \(M\), the coefficient of \(\Lambda(n)(y/n - 1)_+\) in \(G^\psi(y)\) is \(4o/(3o + 1)\) if \(\psi(n) = 1\), and \(3o/(3o + 1)\) otherwise. For a character of order \(4\) modulo \(5\) these are \(16/13\) and \(12/13\).

Tag 222W

Problem 1.4.2. For \(n = p^h\) with \(p \mid M\) the coefficient is at least \(3o/(3o + 1)\). In particular every coefficient is positive.

Tag 222X

Problem 1.4.3. \((3o+1)\) times the Mellin transform of \(G^\psi\) has, in \(\operatorname{Re}s > 0\), simple poles only, at the zeros of \(E(s) := \zeta(s)^{3o+1} \prod_{j=1}^{o-1} L(s, \psi_j)\) in the critical strip. At a zero \(\rho\) of \(E\) of multiplicity \(m\) the residue is \(-m/\bigl(\rho(\rho - 1)\bigr)\).

The multiplicities of the factors of \(E\) add, so no zero of \(\zeta\) or of an \(L(s, \psi_j)\) is cancelled. A real zero \(\beta \in (0, 1)\) of some \(L(s, \psi_j)\) cannot be excluded in advance, but its residue \(m/(\beta(1-\beta))\) is positive, and Problem 1.2.4 applies to it unchanged. As in Problem 1.2.2, \(\sigma_c > -\infty\) because the nonreal zeros of \(\zeta\) are poles. The argument of §1.2 therefore gives:

Tag 222Y

Theorem 1.4.1. Let \(0 < \theta < 1\). If \(G^\psi(y) \le y^\theta\) for all large \(y\), then \(\zeta(s)\) and every \(L(s, \psi_j)\), \(1 \le j < o\), are nonzero for \(\operatorname{Re}s > \theta\).

For \(o = 1\) this is Theorem 1.2.1. The version on intervals follows from Theorem 1.2.2 as before, unless the supremum \(\Theta\) of the real parts of the zeros of \(E\) is itself a real zero in \((\theta, 1)\); then the last hypothesis of Theorem 1.2.2 fails. The next section treats that case.

§1.5. A real zero on windows Tag 222Z

Suppose that \(G^\psi(y) \le y^\theta\) for all \(y \in [Y, Y^{3/2}]\), for arbitrarily large \(Y\), and that \(\Theta = \beta \in (\theta, 1)\) is a real zero of \(E\), of multiplicity \(m\). Let \(\mathcal{A}(s) := \int_1^\infty G^\psi(y) y^{-s-1} \, d y\), and for \(\sigma_1 > 2\) and integers \(k \ge 0\) let \[T_k := \frac{(-1)^k}{k!} \mathcal{A}^{(k)}(\sigma_1) , \qquad r := \sigma_1 - \beta , \qquad a := \sigma_1 - 2 .\] We follow [Adr, Thm. 2.4 and Cor. 2.5], where the nearest pole may also be a pair of complex zeros, and [Rub and Part II, §1].

Tag 2232

Problem 1.5.1. (i) \(\lvert G^\psi(y) \rvert \le B y^2\) for \(y \ge 1\), with \(B\) a constant. (ii) \(T_k = \int_0^\infty G^\psi(e^u) \, e^{-\sigma_1 u} u^k/k! \, d u\). (iii) For \(p \ne \sigma_1\), the signed Taylor coefficient \(\frac{(-1)^k}{k!} \frac{d^k}{d s^k} (s - p)^{-1}\) at \(s = \sigma_1\) is \((\sigma_1 - p)^{-k-1}\).

Tag 2233

Problem 1.5.2. For every real \(\sigma_1 > 1\), \(\beta\) is the only zero of \(E\) in the closed disc \(\lvert s - \sigma_1 \rvert \le \sigma_1 - \beta\). The residue of \(\mathcal{A}\) at \(\beta\) is \(R := m/\bigl((3o+1)\beta(1 - \beta)\bigr) > 0\).

Tag 2234

Problem 1.5.3. There are \(r'' > r\) and \(C\) with \(\lvert T_k - R r^{-k-1} \rvert \le C r''^{-k}\) for all \(k\). Hence \(T_k \ge \frac12 R r^{-k-1}\) for all large \(k\).

So the nearest real pole contributes a positive term to every signed Taylor coefficient. A conjugate pair \(p, \bar p\) would contribute \(2 \lvert c \rvert r^{-k-1} \cos(\alpha + (k+1)\varphi)\), of both signs, where \(c = \lvert c \rvert e^{i\alpha}\) is the residue and \(\sigma_1 - p = r e^{-i\varphi}\); compare Problem 1.1.8. An upper bound for \(G^\psi\) bounds every \(T_k\) from above, because the kernel \(e^{-\sigma_1 u}u^k/k!\) is positive. Only the window \([L, \frac32 L]\), \(L := \log Y\), is controlled; but for \(k\) near \(\frac65 a L\) the kernel \(e^{-au} u^k/k!\) is concentrated near \(u = k/a\), inside the window.

Tag 2235

Problem 1.5.4. Let \(U \ge 0\) and \(a > 0\). If \(b > a\), then \(\int_0^U e^{-au} u^k/k! \, d u \le e^{(b - a)U} b^{-k-1}\). If \(0 < b < a\), then \(\int_U^\infty e^{-au} u^k/k! \, d u \le e^{-(a - b)U} b^{-k-1}\).

Tag 2236

Problem 1.5.5. Let \(\sigma_1 \ge 302\), let \(L = \log Y \ge 1\) for one of the \(Y\) above, and let \(k + 1 := \lceil \frac65 a L \rceil\). Then \[T_k \le (\sigma_1 - \theta)^{-k-1} + 2 B e^{-L} r^{-k-1} .\]

Tag 2237

Problem 1.5.6. Problems 1.5.3 and 1.5.5 contradict each other as \(Y \to \infty\). So the window bound excludes a real zero \(\beta = \Theta\) in \((\theta, 1)\).

With Theorem 1.2.2 for the other case, this proves the version on intervals of Theorem 1.4.1.

Tag 2238

Theorem 1.5.1. Let \(0 < \theta < 1\). If there are arbitrarily large \(Y\) such that \(G^\psi(y) \le y^\theta\) for all \(y \in [Y, Y^{3/2}]\), then \(\zeta(s)\) and every \(L(s, \psi_j)\), \(1 \le j < o\), are nonzero for \(\operatorname{Re}s > \theta\).
