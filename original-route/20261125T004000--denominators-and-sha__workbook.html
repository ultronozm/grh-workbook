§29.1. Denominators of linear maps Tag 22SG

A linear map between \(\mathbb{Q}\)-vector spaces with integral structures need not respect them. What does that cost in a slope inequality, and how can it be reduced? The simplest example is differentiation. Let \(\mathrm{Int}\) be the set of polynomials \(f \in \mathbb{Q}[x]\) with \(f(\mathbb{Z}) \subseteq \mathbb{Z}\), and let \(\mathrm{Int}_n\) be its elements of degree at most \(n\).

Tag 22SH

Problem 29.1.1. The binomial polynomials \(\binom{x}{k}\), \(0 \le k \le n\), form a \(\mathbb{Z}\)-basis of \(\mathrm{Int}_n\).

Tag 22SJ

Problem 29.1.2. Let \(D = d/dx\). Then \[D \binom{x}{n} = \sum_{k=1}^{n} \frac{(-1)^{k-1}}{k} \binom{x}{n-k} .\] Hence the least positive integer \(c\) with \(c \, D(\mathrm{Int}_n) \subseteq \mathrm{Int}\) is \(\operatorname{lcm}(1, 2, \dots, n)\).

The logarithm of this denominator is \(\sum_{p^a \le n} \log p\), of the size of \(n\). Alpöge’s note records a “need for division” [Alp, item 14]. In the reconstruction [Adr] the defect sits at the places where the local type of the theta lifts is twisted: there the lattice of integral lifted forms differs from the lattice that the period pairing sees, and a congruence module measures the difference.

An integral structure can be built one prime at a time. For a lattice \(L \subset \mathbb{Q}^r\) and a prime \(p\), write \(L_p := L \otimes \mathbb{Z}_p \subset \mathbb{Q}_p^r\).

Tag 22SK

Problem 29.1.3. For every family \((\Lambda_p)_p\) of \(\mathbb{Z}_p\)-lattices \(\Lambda_p \subset \mathbb{Q}_p^r\) with \(\Lambda_p = \mathbb{Z}_p^r\) for all but finitely many \(p\), there is exactly one lattice \(L \subset \mathbb{Q}^r\) with \(L_p = \Lambda_p\) for every \(p\), namely \(L = \bigcap_p (\Lambda_p \cap \mathbb{Q}^r)\). If \(\Lambda_2 = \tfrac12 \mathbb{Z}_2 \oplus \mathbb{Z}_2\), \(\Lambda_3 = \mathbb{Z}_3 \oplus \tfrac13 \mathbb{Z}_3\), and \(\Lambda_p = \mathbb{Z}_p^2\) otherwise, then \(L = \tfrac12\mathbb{Z}\oplus \tfrac13\mathbb{Z}\).

For a finitely generated torsion \(\mathbb{Z}_p\)-module \(T\) let \(\operatorname{len}_{\mathbb{Z}_p} T\) be its length.

Tag 22SL

Problem 29.1.4. If \(T\) is a finite abelian group, then \(\log \lvert T \rvert = \sum_p \operatorname{len}_{\mathbb{Z}_p}(T \otimes \mathbb{Z}_p) \log p\). If \(M' \subseteq M\) are lattices of the same rank, then \(\log [M : M'] = \sum_p \operatorname{len}_{\mathbb{Z}_p}(M_p/M'_p) \log p\).

Let \(L\) and \(M\) be Euclidean lattices and \(T \colon L_\mathbb{Q}\to M_\mathbb{Q}\) an injective linear map. If \(T(L) \not\subseteq M\), one may replace \(M\) by the lattice \(M + T(L)\), with the same norm.

Tag 22SM

Problem 29.1.5. \(\mu_{\max}(M + T(L)) \le \mu_{\max}(M) + \log [M + T(L) : M]\). Hence \(\mu(L) \le \mu_{\max}(M) + h_\infty(T) + \log [M + T(L) : M]\).

The index term in Theorem 6.5.1 has the same origin. So a denominator costs \(\log\lvert(M + T(L))/M\rvert\), a sum of local terms by Problem 29.1.4. If several maps \(T_1, \dots, T_k\) serve equally well, for instance because they have the same period, one may choose at each prime the lattice \((M + T_j(L))_p\) of smallest index over \(M_p\), and Problem 29.1.3 assembles the choices into one lattice \(M^*\). A map carrying \(L\) into \(M^*\) must then be found separately; for the Stickelberger element below it is a combination of the twists.

Tag 22SN

Problem 29.1.6. Let \(M_j := M + T_j(L)\), and let \(M^*\) be the lattice with \(M^*_p = (M_j)_p\) for a \(j = j(p)\) that minimizes \(\operatorname{len}_{\mathbb{Z}_p}\bigl((M_j)_p/M_p\bigr)\). Then \(M^* \supseteq M\) and \[\log [M^* : M] = \sum_p \min_j \operatorname{len}_{\mathbb{Z}_p}\bigl((M_j)_p/M_p\bigr) \log p .\] If \(M = \mathbb{Z}\) and \(M_j = D_j^{-1}\mathbb{Z}\) with positive integers \(D_j\), then \([M^* : M] = \gcd(D_1, \dots, D_k)\). For \(D_j = 6, 10, 15\) each map alone costs at least \(\log 6\), and together they cost nothing.

Alpöge’s note glues its integral structures in this way, “across Hecke characters for a ‘gcd’ ” [Alp, item 15]. What no twist removes is, at each prime, a finite module that it identifies with a group of Galois cohomology classes [Alp, item 17]; in the reconstruction the congruence modules are bounded by lengths of Tate–Shafarevich groups of Tate twists, through deformation rings and Wach modules [Adr and 17.5], so the Stickelberger element below is a model of the minus part only. The simplest instance, a rational element whose twists are integral and whose remainder is measured by a class group, is the Stickelberger element of \(\mathbb{Q}(\zeta_p)\).

§29.2. The Stickelberger element Tag 22SP

Let \(p\) be an odd prime, \(F := \mathbb{Q}(\zeta_p)\), \(G := \operatorname{Gal}(F/\mathbb{Q})\), and let \(\sigma_a \in G\) be the automorphism with \(\sigma_a(\zeta_p) = \zeta_p^a\). Let \(A\) be the \(p\)-primary part of \(\operatorname{Cl}(F)\), a \(\mathbb{Z}_p[G]\)-module. Let \(\omega \colon (\mathbb{Z}/p\mathbb{Z})^\times \to \mathbb{Z}_p^\times\) be the Teichmüller character, with \(\omega(a) \equiv a \pmod p\), and view it as a character of \(G\). For \(i \in \mathbb{Z}/(p-1)\mathbb{Z}\) let \(A^{(i)} := \{ z \in A : \sigma_a z = \omega(a)^i z \text{ for all } a \}\), and \[\varepsilon_i := \frac{1}{p-1} \sum_{a=1}^{p-1} \omega(a)^i \sigma_a^{-1} \in \mathbb{Z}_p[G] .\]

Tag 22SQ

Problem 29.2.1. The \(\varepsilon_i\) are orthogonal idempotents with sum \(1\), \(\sigma_a \varepsilon_i = \omega(a)^i \varepsilon_i\), and \(A = \bigoplus_i \varepsilon_i A = \bigoplus_i A^{(i)}\). Complex conjugation \(\sigma_{-1}\) acts on \(A^{(i)}\) by \((-1)^i\).

Write \(A^+\) and \(A^-\) for the sums of the \(A^{(i)}\) with \(i\) even and with \(i\) odd.

Tag 22SR

Problem 29.2.2. If \(K \subseteq F\), then extension of ideals identifies the \(p\)-primary part of \(\operatorname{Cl}(K)\) with \(A^{\operatorname{Gal}(F/K)}\). Hence \(A^{(0)} = 0\), \(A^+\) is the \(p\)-primary part of the class group of \(F^+ := \mathbb{Q}(\zeta_p + \zeta_p^{-1})\), and if \(p \equiv 1 \pmod 4\), then \(A^{((p-1)/2)}\) is the \(p\)-primary part of \(\operatorname{Cl}(\mathbb{Q}(\sqrt{p}))\).

The Stickelberger element is \[\theta := \frac1p \sum_{a=1}^{p-1} a \, \sigma_a^{-1} \in \mathbb{Q}[G] ,\] with the denominator \(p\). We use Stickelberger’s theorem as a black box [Wa, Thm. 6.10].

Tag 22SS

Theorem 29.2.1 (Stickelberger). If \(\beta \in \mathbb{Z}[G]\) and \(\beta\theta \in \mathbb{Z}[G]\), then \(\beta\theta\) annihilates \(\operatorname{Cl}(F)\).

The integral multiples of \(\theta\) are its twists.

Tag 22ST

Problem 29.2.3. For \(c\) prime to \(p\), \((c - \sigma_c)\theta = \sum_{b=1}^{p-1} \lfloor cb/p \rfloor \, \sigma_b^{-1}\). In particular \((c - \sigma_c)\theta \in \mathbb{Z}[G]\).

For a nontrivial Dirichlet character \(\chi\) modulo \(p\) let \(B_{1,\chi} := \frac1p \sum_{a=1}^{p-1} \chi(a)\, a\).

Tag 22SU

Problem 29.2.4. \(\varepsilon_i \theta = B_{1,\omega^{-i}} \varepsilon_i\) for \(i \not\equiv 0\). If \(i \not\equiv 0\) is even, then \(B_{1,\omega^{-i}} = 0\).

So \(\theta\) says nothing about \(A^+\). On \(A^{(i)}\) the twist \((c - \sigma_c)\theta\) acts as \((c - \omega(c)^i)B_{1,\omega^{-i}}\), and the gluing of Problem 29.1.6 asks for the ideal generated by the factors \(c - \omega(c)^i\).

Tag 22SV

Problem 29.2.5. The ideal of \(\mathbb{Z}_p\) generated by the numbers \(c - \omega(c)^i\), \(c\) prime to \(p\), is \(\mathbb{Z}_p\) if \(i \not\equiv 1\) and \(p\mathbb{Z}_p\) if \(i \equiv 1\). Moreover \(v_p(B_{1,\omega^{-1}}) = -1\).

Thus on each \(A^{(i)}\) with \(i \not\equiv 0, 1\) the twists together act as \(B_{1,\omega^{-i}} \in \mathbb{Z}_p\): the gluing recovers the eigenvalue of \(\theta\) itself. On \(A^{(1)}\) every factor \(c - \omega(c)\) is divisible by \(p\) and cancels the denominator of \(B_{1,\omega^{-1}}\), so the twists generate \(\mathbb{Z}_p\) and not \(p^{-1}\mathbb{Z}_p\): the gluing does not recover the eigenvalue of \(\theta\). This \(p\) is the order of \(\mu_p\), on which \(G\) acts by \(\omega\). (The group \(A^{(1)}\) vanishes for another reason [Wa, Prop. 6.16].) By Kummer’s congruences [Wa, Ch. 5], if \(i\) is odd and \(3 \le i \le p-2\), then \[\begin{equation} \label{eq:kummer}\tag{1} B_{1,\omega^{-i}} \equiv \frac{B_{p-i}}{p-i} \pmod p . \end{equation}\]

Tag 22SW

Problem 29.2.6. For \(p = 7\) the character \(\omega^{-3}\) is the Legendre symbol, \(B_{1,\omega^{-3}} = -1\), and \(B_4/4 = -1/120 \equiv -1 \pmod 7\).

Tag 22SX

Problem 29.2.7. Let \(i\) be odd with \(3 \le i \le p-2\). If \(p \nmid B_{p-i}\), then \(A^{(i)} = 0\).

This is Herbrand’s theorem [Wa, Thm. 6.17]. Its converse is due to Ribet [Ri], and the exact order to Mazur and Wiles [MW]; see [Wa, Ch. 15]. We use them as a black box.

Tag 22SY

Theorem 29.2.2 (Herbrand, Ribet, Mazur–Wiles). Let \(i\) be odd with \(3 \le i \le p-2\). Then \(A^{(i)} \ne 0\) if and only if \(p \mid B_{p-i}\), and \(\lvert A^{(i)} \rvert = \lvert B_{1,\omega^{-i}} \rvert_p^{-1}\).

Tag 22SZ

Problem 29.2.8. For \(p < 100\), the pairs \((p, k)\) with \(k\) even, \(2 \le k \le p-3\) and \(p \mid B_k\) are \((37, 32)\), \((59, 44)\) and \((67, 58)\). Hence for \(p < 100\) the group \(A^-\) is nonzero only for \(p = 37, 59, 67\), and then exactly one odd eigenspace is nonzero, \(A^{(5)}\), \(A^{(15)}\) and \(A^{(9)}\) respectively.

The plus part \(A^+\) is not seen by \(\theta\) (Problem 29.2.4). Its order is the \(p\)-part of an index of cyclotomic units in the units of \(F^+\) [Wa, Thm. 8.2]. Vandiver’s conjecture, that \(A^+ = 0\) for every \(p\), has not been proved; it has been verified for \(p < 2^{31}\) [HHO]. The next chapter meets the same division between minus and plus parts in Galois cohomology.
