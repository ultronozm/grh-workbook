Lattices in a Euclidean space and their covolumes [Ne, Ch. I, §4]; the adjoint of a linear map between inner product spaces. The von Mangoldt function \(\Lambda\) and Mertens’ estimate \(\sum_{n \le x} \Lambda(n)/n = \log x + O(1)\). §8.1. The auxiliary polynomial Tag 228A

How can a polynomial show that a set of about \(q/2\) elements of \(\mathbb{F}_q\) has at most \(q/2 + O(\sqrt q)\) elements? Stepanov’s answer [Ste69] is to make it vanish to high order on the set. We follow his method for the curve \(y^2 = f(x)\).

Let \(q\) be a power of an odd prime \(p\), and let \(f \in \mathbb{F}_q[X]\) have odd degree \(d = 2g + 1\) with \(3 \le d < q\). Let \[c := \frac{q-1}{2} , \qquad D := \frac{q-d}{2} .\] For \(\eta \in \{1, -1\}\) let \(S_\eta := \{x \in \mathbb{F}_q : f(x)^c = \eta\}\), let \(S_0 := \{x \in \mathbb{F}_q : f(x) = 0\}\), and let \(N^{\mathrm{aff}}\) be the number of solutions \((x, y) \in \mathbb{F}_q^2\) of \(y^2 = f(x)\).

Tag 228B

Problem 8.1.1. \(\mathbb{F}_q\) is the disjoint union of \(S_1\), \(S_{-1}\) and \(S_0\), and \(N^{\mathrm{aff}}= 2\lvert S_1 \rvert + \lvert S_0 \rvert\). For \(q = 7\) and \(f = X^3 - X\), \(S_1 = \{4, 5\}\), \(S_{-1} = \{2, 3\}\) and \(N^{\mathrm{aff}}= 7\).

Hence \(N^{\mathrm{aff}}- q = \lvert S_1 \rvert - \lvert S_{-1} \rvert\), and a bound \(\lvert S_\eta \rvert \le q/2 + B\) for both signs gives \(\lvert N^{\mathrm{aff}}- q \rvert \le 2B + d\). For squarefree \(f\), Weil’s theorem [Wei48] gives \(\lvert N^{\mathrm{aff}}- q \rvert \le 2g\sqrt q\).

The principle is the count of zeros against the degree: if \(F \in \mathbb{F}_q[X]\) is nonzero and vanishes to order at least \(\ell\) at every point of \(S_\eta\), then \[\begin{equation} \label{eq:count}\tag{1} \ell\, \lvert S_\eta \rvert \le \deg F . \end{equation}\] The polynomials \(f^c - \eta\) and \(X^q - X\) vanish on \(S_\eta\), and give \(\lvert S_\eta \rvert \le dc\) and \(\lvert S_\eta \rvert \le q\). To reach \(q/2\) one needs \(\deg F/\ell\) close to \(q/2\). Stepanov combines the two polynomials. Let \(J \ge 1\) be an integer, and let \(r_j, s_j \in \mathbb{F}_q[X]\), for \(0 \le j < J\), have degree less than \(D\) and be not all zero. Define the auxiliary polynomial by \[\begin{equation} \label{eq:aux}\tag{2} F := \sum_{j<J} \bigl( r_j + s_j f^c \bigr) X^{jq} . \end{equation}\]

Tag 228C

Problem 8.1.2. \(\deg f^c = gq + D\), and \(2D < q\).

Tag 228D

Problem 8.1.3. The nonzero terms \(r_j X^{jq}\) and \(s_j f^c X^{jq}\) of (2) have pairwise distinct degrees. Hence \(F \ne 0\) and \(\deg F \le (J + g)q - d - 1\).

For \(x \in S_\eta\) we have \(x^{jq} = x^j\) and \(f(x)^c = \eta\), so \(F(x) = C_0(x)\), where \[C_0 := \sum_{j<J} (r_j + \eta s_j) X^j .\] If \(C_0 = 0\), then \(F\) vanishes on all of \(S_\eta\).

Tag 228E

Problem 8.1.4. If \(C_0 = 0\), then \(\deg F \ge q\). If \(D \ge 2\) and \(J \ge 2\), the tuple \(r_0 = -X\), \(r_1 = 1\), all others zero, gives \(F = X^q - X\).

Used in: Chapter 7

So the gain must come from the order of vanishing.

§8.2. Vanishing to order \(\ell\) Tag 228F

In characteristic \(p\) the derivative of order \(p\) vanishes identically, so one uses Hasse derivatives. For \(G \in \mathbb{F}_q[X]\) define \(H^k G \in \mathbb{F}_q[X]\) by \[G(X + Y) = \sum_{k \ge 0} (H^k G)(X)\, Y^k \qquad \text{in } \mathbb{F}_q[X, Y] .\]

Tag 228G

Problem 8.2.1. For \(0 \le k \le n\), \(H^k(X^n) = \binom{n}{k} X^{n-k}\), and \(H^k(X^n) = 0\) for \(k > n\). Also \(H^k(G_1 G_2) = \sum_{i \le k} H^i G_1 \cdot H^{k-i} G_2\). For \(\alpha \in \mathbb{F}_q\), \((X - \alpha)^\ell\) divides \(G\) if and only if \((H^k G)(\alpha) = 0\) for all \(k < \ell\).

Tag 228H

Problem 8.2.2. \((X + Y)^{jq} = (X^q + Y^q)^j\). Hence \(H^k(G X^{jq}) = (H^k G) X^{jq}\) for \(k < q\).

To differentiate \(f^c\), write \(f(X + Y)^c = f(X)^c \bigl( f(X+Y)/f(X) \bigr)^c\) and define \(U_i \in \mathbb{F}_q(X)\) by \[\Bigl( \frac{f(X + Y)}{f(X)} \Bigr)^c = \sum_{i \ge 0} \frac{U_i}{f^i}\, Y^i \qquad \text{in } \mathbb{F}_q(X)[[Y]] .\]

Tag 228J

Problem 8.2.3. Each \(U_i\) is a polynomial of degree at most \(i(d-1)\). Moreover \(U_0 = 1\) and \(U_1 = c f'\).

For \(k \ge 0\) let \[\begin{equation} \label{eq:Ck}\tag{3} C_k := \sum_{j<J} \Bigl( f^k H^k r_j + \eta \sum_{i \le k} f^{k-i} U_i\, H^{k-i} s_j \Bigr) X^j . \end{equation}\] For \(k = 0\) this is the polynomial \(C_0\) of Section 8.1.

Tag 228K

Problem 8.2.4. Let \(\alpha \in S_\eta\), so that \(f(\alpha) \ne 0\), and let \(k < q\). Then \((H^k F)(\alpha) = f(\alpha)^{-k} C_k(\alpha)\).

Tag 228L

Problem 8.2.5. \(\deg C_k \le D + J - 2 + k(d-1)\).

By Problems 8.2.1 and 8.2.4, if \(\ell \le q\) and \[\begin{equation} \label{eq:conditions}\tag{4} C_0 = C_1 = \dots = C_{\ell-1} = 0 , \end{equation}\] then \(F\) vanishes to order at least \(\ell\) at every point of \(S_\eta\), whatever \(S_\eta\) is.

§8.3. The count and the balance Tag 228M

Tag 228N

Problem 8.3.1. If \(2JD > \ell(D + J - 1) + (d-1)\ell(\ell-1)/2\), then there is an auxiliary polynomial (2) satisfying (4).

Used in: Problem 8.3.2
Tag 228P

Problem 8.3.2. Let \(\ell\) be an even integer with \(0 \le \ell < q - d\), and let \(J = \ell/2 + t\). Then \[2JD - \ell(D + J - 1) - (d-1)\frac{\ell(\ell-1)}{2} = t\,(q - d - \ell) - \frac{d\ell^2 - (d+1)\ell}{2} .\] Hence the hypothesis of Problem 8.3.1 holds if \(t > d\ell^2/\bigl(2(q - d - \ell)\bigr)\).

The preceding problems give the following estimate.

Tag 228Q

Theorem 8.3.1 (A bound by Stepanov’s method). Let \(\ell\) be even with \(2 \le \ell < q - d\), and let \(t := \lfloor d\ell^2/(2(q - d - \ell)) \rfloor + 1\). Then, for \(\eta = \pm 1\), \[\lvert S_\eta \rvert \le \frac{q}{2} + \frac{(g + t)\, q}{\ell} .\]

Used in: Problem 8.3.4; Chapter 7

This is Stepanov’s method [Ste69]; see [Sch76] for Hasse derivatives. For example, for \(q = 1009\), \(d = 3\) and \(\ell = 24\) one has \(t = 1\), and the bound is \(588.58\ldots\); for \(f = X^3 + X + 1\) the sets have \(\lvert S_1 \rvert = 516\) and \(\lvert S_{-1} \rvert = 492\).

Tag 228R

Problem 8.3.3. If \(q \ge 16d^2\) and \(\ell\) is an even integer with \(\lvert \ell - \sqrt q \rvert \le 1\), then \(\lvert S_\eta \rvert \le q/2 + 2d\sqrt q\) for \(\eta = \pm 1\), and \(\lvert N^{\mathrm{aff}}- q \rvert \le 4d\sqrt q + d\).

Where does the square root come from? Write \((J + g)q - d - 1 = \frac{\ell}{2} q + \bigl((g+1)q - d - 1\bigr) + (t - 1) q\). After division by \(\ell\) the first term is the main term \(q/2\). The second is paid once, however high the order. The third comes from the growing number of equations of the \(k\)th identity, through \(t - 1 = \lfloor d\ell^2/(2(q - d - \ell)) \rfloor\). For fixed \(d\) and \(d + \ell \le q/2\) the error term is \(O_d(q/\ell + \ell)\), of the shape \(q/m + m\), and the two terms of this upper bound balance at \(\ell\) of order \(\sqrt q\).

Tag 228S

Problem 8.3.4. For every \(\ell\) as in Theorem 8.3.1, \((g + t)q/\ell > \sqrt{2gdq}\).

Thus the error term in Theorem 8.3.1 never gives \(o(\sqrt q)\). We expect the same for Bombieri’s form [Bom74], but do not prove it here.

§8.4. The chain inequality Tag 228T

What does a chain of \(m\) linear maps give that one map does not?

Let \(V\) and \(W\) be Euclidean spaces of the same dimension \(n \ge 1\), with lattices \(L \subset V\) and \(M \subset W\) of rank \(n\). We define the volume of a linear map \(u \colon V \to W\) to be \(\det(u^* u)\), where \(u^*\) is the adjoint; in orthonormal bases it is \((\det u)^2\).

Tag 2346

Problem 8.4.1. Let \(u \colon V \to W\) be injective, and let \(\lambda > 0\) be real with \(u(L) \subseteq \lambda M\). Then \[n \log \lambda \le \log \operatorname{covol}(L) - \log \operatorname{covol}(M) + \tfrac12 \log \det(u^* u) .\] For \(L = M = \mathbb{Z}\), \(u\) the multiplication by \(6\) and \(\lambda = 6\), both sides are \(\log 6\).

Used in: Problem 8.4.4, Problem 8.4.5, Problem 8.5.3

Let \(m \ge 1\) be an integer, and let \(V_0, \dots, V_m\) be Euclidean spaces of dimension \(n\) with lattices \(L_j \subset V_j\) of rank \(n\). Let \(u_j \colon V_{j-1} \to V_j\) be linear maps and \(\lambda_j > 0\) real numbers with \(u_j(L_{j-1}) \subseteq \lambda_j L_j\), and let \(\Psi := u_m \circ \dots \circ u_1\).

Tag 2347

Problem 8.4.2. \(\det(\Psi^* \Psi) = \prod_{j=1}^m \det(u_j^* u_j)\), also when some \(u_j\) is not injective. The identity fails for spaces of different dimensions: for \(u_1(x) = (x, 0)\) from \(\mathbb{R}\) to \(\mathbb{R}^2\) and \(u_2(y, z) = y\) from \(\mathbb{R}^2\) to \(\mathbb{R}\) the left side is \(1\) and the right side is \(0\).

Tag 228V

Problem 8.4.3. \(\Psi(L_0) \subseteq \lambda_1 \cdots \lambda_m L_m\). In particular, if \(u_j(L_{j-1}) \subseteq p^{e_j} L_j\) for each \(j\), then \(\Psi(L_0) \subseteq p^{e_1 + \dots + e_m} L_m\).

Used in: Chapter 25

For the composite of the chain we have the following inequality; if \(\Psi\) is injective, then so is every \(u_j\), because all dimensions are equal.

Tag 228W

Theorem 8.4.1 (Chain inequality). If \(\Psi\) is injective, then \[n \sum_{j=1}^m \log \lambda_j \le \log \operatorname{covol}(L_0) - \log \operatorname{covol}(L_m) + \frac12 \sum_{j=1}^m \log \det(u_j^* u_j) .\]

Used in: Problem 8.4.4, Problem 8.4.5; Chapter 7

The right side uses the two ends and the volume of each step, and the ends are paid once: if \(\Psi\) is injective, \(\log \lambda_j \ge \beta\) and \(\frac{1}{2n} \log \det(u_j^* u_j) \le \sigma\) for every \(j\), and \(\frac1n (\log \operatorname{covol}(L_0) - \log \operatorname{covol}(L_m)) \le c_{\mathrm{end}}\), then \(\beta \le \sigma + c_{\mathrm{end}}/m\).

Tag 228X

Problem 8.4.4. Suppose that every \(u_j\) is injective. The sum of the inequalities of Problem 8.4.1 for \(u_1, \dots, u_m\) and \(\lambda_1, \dots, \lambda_m\) is the inequality of Theorem 8.4.1.

Measured by volumes, then, the intermediate lattices cost nothing. The product of the operator norms, by contrast, can strictly exceed the operator norm of the composite.

Tag 228Y

Problem 8.4.5. Let \(w \ge 2\) be an integer, \(L_0 = L_2 = \mathbb{Z}^2\) and \(L_1 = \mathbb{Z}e_1 + \mathbb{Z}w e_2\), all in \(\mathbb{R}^2\) with the standard norm, and let \(u_1(x, y) = (x, wy)\) and \(u_2(x, y) = (x, y/w)\). Then \(\lambda_1 = \lambda_2 = 1\) are the largest admissible scalars, \(\det(u_1^* u_1) = w^2\), \(\det(u_2^* u_2) = w^{-2}\), and the inequalities of Problem 8.4.1 for \(u_1\), \(u_2\) and of Theorem 8.4.1 are equalities. But \(\lVert u_1 \rVert \, \lVert u_2 \rVert = w\), while \(\Psi\) is the identity.

A divisibility is often known only on a sublattice. Its index is a loss, paid once.

Tag 2348

Problem 8.4.6. Suppose that \(\Psi\) is injective and that \(\Psi(L_0') \subseteq \lambda L_m\) for a sublattice \(L_0' \subseteq L_0\) of finite index and a real \(\lambda > 0\). Then \[n \log \lambda \le \log \operatorname{covol}(L_0) - \log \operatorname{covol}(L_m) + \frac12 \sum_{j=1}^m \log \det(u_j^* u_j) + \log\, [L_0 : L_0'] .\]

Theorem 6.2.1 gives a related index and covolume inequality for a twisted lattice. For the chain of the proof, the determinant divided by its value at the trivial twist is the product of the corresponding quotients for the single lifts, times a correction factor (Theorem 68.4.1). This factor is a power of the norm of the modulus times a product of ratios of absolute values of partial Hecke \(L\)-values, all raised to the dimension of the target forms.

How precisely must the two ends and the volumes of the steps be known?

§8.5. The budget \(x/m + m\) Tag 228Z

How long should the chain be? Let \(G(x) = \sum_{n \le x} \Lambda(n) (x/n - 1) - x\log x + (1 + \gamma)x\) be the function of (1) in Chapter 1. By Mertens’ estimate, \(G(x) = O(x)\). By Theorem 1.2.1, if \(G(x) \le x^\theta\) for some \(0 < \theta < 1\) and all large \(x\), then \(\zeta(s) \ne 0\) for \(\operatorname{Re} s > \theta\). So a one-sided bound with exponent \(\tfrac12\) gives the Riemann hypothesis.

Let \(a, b > 0\) and \(x := a/b\). As in Section 1.3, \((a/p^e - b)_+ = b(x/p^e - 1)_+\), so that \[\sum_p \log p \sum_{e \ge 1} \Bigl( \frac{a}{p^e} - b \Bigr)_+ = b \sum_{\nu \le x} \Lambda(\nu) \Bigl( \frac{x}{\nu} - 1 \Bigr) ,\] where \(u_+ := \max(u, 0)\); for integral \(a\) the inner sum is a smoothed analogue of Legendre’s sum \(\sum_{e \ge 1} \lfloor a/p^e \rfloor\) for \(v_p(a!)\). We consider a chain as in Section 8.4, with \(\Psi\) injective, and real numbers \(c_{\mathrm{end}}\) and \(c_1, \dots, c_m\) such that for \(1 \le j \le m\) \[\begin{equation} \label{eq:toy}\tag{5} \begin{gathered} \log \lambda_j \ge b \sum_{\nu \le x} \Lambda(\nu) \Bigl( \frac{x}{\nu} - 1 \Bigr) , \qquad \frac{1}{2n} \log \det(u_j^* u_j) \le a(\log x - 1 - \gamma) + c_j , \\ \frac1n \bigl( \log \operatorname{covol}(L_0) - \log \operatorname{covol}(L_m) \bigr) \le c_{\mathrm{end}} . \end{gathered} \end{equation}\] Here \(c_{\mathrm{end}}\) is the cost at the ends, and \(c_j\) the cost of the \(j\)th step. This models the bookkeeping only.

Tag 2292

Problem 8.5.1. Under (5), \(G(x) \le (c_{\mathrm{end}} + c_1 + \dots + c_m)/(mb)\).

Used in: Chapter 7
Tag 2293

Problem 8.5.2. If \(c_{\mathrm{end}} = a\) and \(c_j = (2j - 1)b\), then \(G(x) \le x/m + m\). With \(m = \lceil \sqrt x \rceil\) this gives \(G(x) \le 2\sqrt x + 1\). For \(x = 10^6\) the bound is \(2000\) at \(m = 1000\) and \(10100\) at \(m = 100\).

Used in: Chapter 7

What happens if the cost at the ends is paid separately for every step?

Tag 2294

Problem 8.5.3. Retain the first two bounds of (5). Suppose that every \(u_j\) is injective and that Problem 8.4.1 is applied to each \(u_j\) separately, with \(\frac1n (\log \operatorname{covol}(L_{j-1}) - \log \operatorname{covol}(L_j)) \le a\) for every \(j\) and \(c_j = (2j-1)b\). Then the \(j\)th step gives \(G(x) \le x + 2j - 1\), so the best of these bounds is \(G(x) \le x + 1\), the bound for \(m = 1\).

Tag 2295

Problem 8.5.4. \(\sum_{j=1}^m (3j^2 - 3j + 1) = m^3\). So if \(c_{\mathrm{end}} = a\) and \(c_j = (3j^2 - 3j + 1)b\), then \(G(x) \le x/m + m^2\). For every \(m > 0\), \(x/m + m^2 \ge 3 \cdot 2^{-2/3} x^{2/3}\). For \(x = 10^6\) the least value over integers \(m\) is \(18899.2\ldots\), at \(m = 79\).

If such chains exist for every sufficiently large \(x\) at a length minimizing the bound in Problem 8.5.4, that bound gives \(G(x) \le x^\theta\) eventually for each \(\theta > 2/3\), and hence a zero-free half-plane \(\operatorname{Re} s > 2/3\) for \(\zeta\). The exponent is decided by how the total cost grows with the length of the chain.

The chain of the proof.

This chapter serves the main inequality. Chapter 38 proves \(m \cdot \mathrm{rem}\le fa\log^5 b\) (Theorem 38.2.1) and deduces a bound for \(R_{d,q_0}(x)\). From here on \(f\) is the number of infinite places of the field \(E\), \(k = r + 1 - m\) is the rank of the source, and \(U = fa\log^3 b\) is the unit of error, all as in Chapter 36 (they are not the polynomial \(f\) and the index \(k\) of Sections 8.1–8.3); the data have \(\sqrt x \le m \le 2\sqrt x\). In the proof two estimates involve \(m\) through \(m^2\) relative to their budgets. First, the level \(N\) is a prime with \(m \log b \le \log N \le 30 m \log b\); the allowed loss at \(N\) is \(2mfb\) (here \(N \ge b > x_1\), so \(N\) is not a small non-split prime); and for every finite set of natural numbers the sum over its elements \(p\) of the allowed loss at \(p\) times \(\log p\), with the summand at \(p = 0\) defined to be zero, is at most \(U\). Second, local defect bounds \(\delta_p\) satisfy \(\sum_{p \in T} \delta_p \log p \le C_{\mathrm{loc}} f (m/k) b \log b\) for every finite set \(T\) of primes, with \(C_{\mathrm{loc}} = 4 \cdot 10^6 e^{180}\), while for each lift index the sum of the logarithmic denominator bounds over every finite set of primes must be at most \(B = U/(mk)\).

Tag 2349

Problem 8.5.5. Let \(m, x, f, k > 0\), \(b > 1\), \(L := \log b\), \(a := xb\) and \(U := faL^3\). (a) If \(mL \le \log N \le 30 mL\), then \(2m^2 fbL \le 2mfb \log N \le 60 m^2 fbL\); hence \(2mfb \log N \le U\) forces \(m \le L\sqrt{x/2}\), and holds if \(m \le L \sqrt{x/60}\). (b) For \(C_{\mathrm{loc}} > 0\), \(C_{\mathrm{loc}} f (m/k) bL \le U/(mk)\) if and only if \(m \le L\sqrt{x/C_{\mathrm{loc}}}\).

The data have \(\log\log b \ge 10^{12} C\), with \(C \ge 1\) the constant of Chapter 36, so both comparisons of Problem 8.5.5 hold in the range \(\sqrt x \le m \le 2\sqrt x\). Up to powers of \(\log b\), the length has the same square-root scale as in Problem 8.5.2.
